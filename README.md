# Image to Bouquet

> 给一张图片，得到一束真实能做出来的花。

`image-to-bouquet` 会读取参考图里的 **配色、重心、节奏和氛围**，再重新设计成一束现实可制作的手绑花束。

它不是把原图“拼成花”，而是保留这张图最重要的视觉感觉。

```text
参考图片
  ↓
色彩 / 重心 / 节奏 / 氛围
  ↓
重新做花艺构图
  ↓
花束成品图 + 花艺师执行单
```

## 怎么用

安装 Skill 后，直接给一张图片：

> 用 image-to-bouquet 把这张图转成一束花。

人物、风景、建筑、专辑封面、插画或抽象图片都可以。

## 你会得到

### 花束成品图

一张独立、清晰的花店产品图。设计会尽量做到：

- 保留原图最有辨识度的色彩和气质；
- 有明确焦点、层次、动势和留白，而不是简单堆颜色；
- 只使用真实可落地的花材、配叶、包装和丝带；
- 不复制人脸、文字、Logo、物体轮廓或原图图案；
- 不用灯、铁丝骨架、卡片等道具制造“效果”。

### 花艺师执行单

同时给出一份简短制作说明，包括花材、数量、包装、结构、替代材料和最需要保留的设计关系。

## 目标

> **让人能感受到参考图的配色与气质，同时得到一束本身就足够漂亮、有设计感、而且真的能做出来的花。**
