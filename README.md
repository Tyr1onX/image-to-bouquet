# Image to Bouquet

> 给一张图片，得到一束真正有设计感、而且能做出来的花。

`image-to-bouquet` 会读取参考图里的 **配色、重心、节奏和气质**，再重新设计成一束花艺作品。

它不是把原图“拼成花”，而是把最重要的视觉感觉转成花材、结构和包装。

```text
参考图片
  ↓
色彩 / 重心 / 节奏 / 气质
  ↓
选择材料与包装
  ↓
重新做花艺设计
  ↓
成品图 + 花艺师执行单
```

## 怎么用

安装 Skill 后，直接给一张图片：

> 用 image-to-bouquet 把这张图转成一束花。

默认会自动选择材料，也可以直接指定：

- **Fresh**：鲜花优先
- **Hybrid**：鲜花 + 永生花 / 干花 / 染色材料
- **Art**：颜色和设计优先，可使用永生花、染色花材和高质量仿真植物

还可以补充要求，例如：

> 颜色尽量贴近原图，做得大胆一点，预算中等，包装也要参与配色。

## 你会得到

- 一张独立、清晰的花艺成品图；
- 一份对应的花艺师执行单，包含材料、数量、包装、替代方案和关键设计关系。

结果会尽量做到：**颜色贴近、花材有选择逻辑、包装参与设计、整体有焦点与层次，同时现实中可以被花艺师复现。**
