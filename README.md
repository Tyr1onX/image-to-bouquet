# Image to Bouquet

> 给一张图片，得到一束真正有设计感、而且现实中能做出来的花。

`image-to-bouquet` 会读取参考图里的 **配色、重心、节奏和气质**，再重新设计成花材与包装。

它不是把原图“拼成花”，而是把最重要的视觉感觉转成一束成立的花。

```text
参考图片
  ↓
色彩 / 重心 / 节奏 / 气质
  ↓
选择花材与包装
  ↓
重新做花艺设计
  ↓
成品图 + 花艺师执行单
```

## 怎么用

安装后，直接给一张图片：

> 用 image-to-bouquet 把这张图转成一束花。

默认会自动选择材料，也可以指定：

- **鲜花**：自然、适合送礼
- **永生花**：适合专辑封面、海报和强配色参考图
- **混合花材**：鲜花 + 永生花 / 干花 / 染色花材
- **艺术花材**：设计与颜色优先，可加入高质量仿真植物

也可以补充：

> 颜色尽量贴近原图，永生花版本；有必要时局部做渐变，包装也参与配色，底部是否露枝按整体效果判断。

## 你会得到

- 一张独立的花束成品图；
- 一份简洁的中文花艺师执行单，包含花材、数量、包装、替代方案与关键设计关系。

默认不会输出安装状态、测试轮次、本地路径、供应商链接等过程信息。

目标是：**颜色贴近、色彩关系合理、花型好看、包装有设计、上下完成度统一，同时花艺师真的能复现。**
