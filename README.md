# Image to Bouquet

> 给一张图片，得到一束真实能做出来的花。

`image-to-bouquet` 是一个很简单的 Agent / Codex Skill：读取参考图的**色彩、几何构图、质感和整体氛围**，把这些视觉关系转译成一束现实可制作、默认控制成本的花束。

参考图可以是风景、随手拍、建筑、人物、插画、海报、专辑封面或任何你觉得好看的图片。

它不负责复制图片里的物体，而是做视觉转译：

```text
色彩 → 花材 / 包装 / 丝带
构图 → 花束轮廓 / 高低 / 重心 / 留白
质感 → 花材与包装材质
氛围 → 饱和度 / 密度 / 克制程度
```

## 输出

一次完整结果包含：

1. **原图** — 单独展示，用来前后对比。
2. **花束成品图** — 只出现一束花，不带说明板、原图缩略图或信息图。
3. **花艺师执行单** — 单独用文字说明花材、数量、包装、尺寸、成本和替代方案。

默认要求花束为中小尺寸、花材不过量、常见材料优先，并且花艺师可以按照执行单真实复现。

核心规则都在 [`SKILL.md`](SKILL.md)。
