# Image to Bouquet

> 给一张图片，得到一束真实能做出来的花。

`image-to-bouquet` 会读取参考图里的 **色彩、构图、质感和氛围**，再把这些视觉关系转译成一束现实可制作、成本可控的花束。

它不追求把图片里的具体人物、建筑、Logo 或物体原样搬进花束，而是保留这张图最重要的视觉感觉。

```text
参考图片
  ↓
色彩 / 构图 / 质感 / 氛围
  ↓
真实可制作的花束
  ↓
花束成品图 + 花艺师执行单
```

## 怎么用

安装 Skill 后，直接给 Codex 一张图片，例如：

> 用 image-to-bouquet 把这张图转成一束花。

不需要提前指定花材。它会根据图片决定花材、包装、结构和整体配色。

参考图可以是风景、人物、随手拍、建筑、插画、海报、专辑封面，或者任何你觉得适合转成花束的图片。

## 你会得到什么

### 1. 花束成品图

一张独立、清晰的花束图片，只展示最终花束和简单背景。

花束会尽量满足：

- 看起来真实，而不是概念艺术；
- 花材、结构和包装能够被花艺师实际复现；
- 保留参考图最重要的颜色关系和整体气质；
- 不把参考图中的具体物体生硬地塞进花束。

### 2. 花艺师执行单

同时给出一份简短的制作说明，包括：

- 花束尺寸与结构；
- 花材和配叶；
- 每种材料的大致数量；
- 包装纸、内衬、丝带等外部材料；
- 简短制作顺序；
- 可替代材料；
- 成本等级；
- 最需要保留的视觉特征。

图片和执行单描述的是 **同一束花**，方便直接拿给花艺师参考。

## 设计原则

### 视觉转译，而不是复制原图

```text
色彩 → 花材 / 包装 / 丝带
构图 → 花束轮廓 / 高低 / 重心 / 留白
质感 → 花材表面 / 配叶 / 包装材质
氛围 → 饱和度 / 密度 / 克制程度
```

### 真实可做

默认避免漂浮物、模型、发光结构等难以落地的装饰。参考图里的具体物体主要作为视觉关系来源，而不是直接复制到花束里。

### 默认控制成本

除非特别说明，默认以中小尺寸花束为主：

- 花材种类不过多；
- 主花数量适中；
- 优先使用常见、容易采购的材料；
- 能通过包装、丝带和配叶完成的颜色关系，不靠额外堆花解决。

目标不是做出最复杂、最昂贵的一束花，而是用尽可能简单、真实的方式，把参考图的感觉留下来。
