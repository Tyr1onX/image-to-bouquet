# Image to Bouquet

> 给一张图片，得到一束真实能做出来的花。

`image-to-bouquet` 是一个很简单的 Agent / Codex Skill：读取参考图的**色彩、几何构图、质感和整体氛围**，把这些视觉关系转译成一束现实可制作、默认控制成本的花束。

参考图可以是风景、随手拍、建筑、人物、插画、海报、专辑封面或任何你觉得好看的图片。

它不复制图片里的具体物体，而是做视觉转译：

```text
色彩 → 花材 / 包装 / 丝带
构图 → 花束轮廓 / 高低 / 重心 / 留白
质感 → 花材与包装材质
氛围 → 饱和度 / 密度 / 克制程度
```

## 输出

一次完整结果只需要两样东西：

1. **花束成品图** — 必须直接调用原生图片生成工具生成，只出现一束真实可复现的花，不带说明板、原图缩略图或信息图。
2. **花艺师执行单** — 一份简短 Markdown 文档，写清花材与数量、包装与丝带、尺寸与结构、制作顺序、替代材料和成本等级。

花束图和执行单必须描述**同一束花**。

默认要求：中小尺寸、3–5 类主要材料、约 7–12 个主要花头/枝、常见花材优先，不过度堆料，不加入无法真实制作的装饰物。

核心规则全部放在 [`SKILL.md`](SKILL.md)，仓库不需要复杂框架。

## 在 Codex 中测试

安装/引用本仓库 Skill 后，给 Codex 一张图片并直接说：

> 用 image-to-bouquet 把这张图转成花束。生成最终花束图片，并给出简短的花艺师执行单。

正常完成时，你应该得到：

```text
reference image
→ bouquet image
→ florist build sheet
```
