# Image to Bouquet

给一张参考图，生成一束**有设计感、现实中能制作的花束**。

它会提取参考图的配色、重心、节奏和气质，再重新设计花材与包装，而不是把原图直接“拼成花”。

## 怎么用

安装 Skill 后，上传一张图片并说：

> 用 image-to-bouquet 把这张图转成一束花。

需要时可以直接加要求，例如：

> 做成永生花，颜色尽量贴近原图，包装也参与配色。

支持鲜花、永生花、混合花材和艺术花材；未指定时会自动选择。

## 你会得到

- 一张花束成品图
- 一份中文花艺师执行单，包含花材、数量、包装和替代方案

适合专辑封面、人物、插画、风景等参考图。
