# Image to Bouquet

> 给一张图片，得到一束花。

`image-to-bouquet` 是一个面向 Agent / Codex 的花束设计 Skill。它把参考图片中的**颜色、构图、质感、情绪与视觉符号**转译成一束真实可制作的花，而不是机械地“按颜色配花”。

## 输入

任意参考图片：照片、专辑封面、海报、插画、电影画面、Logo、游戏截图……

## 输出

每次完整执行必须同时交付两样东西：

1. **花束效果图** — 一张能够直接展示设计结果的图片。
2. **花艺师执行单** — 花材、数量/比例、包装、尺寸、结构、制作顺序、替代规则，以及必须保留/避免的视觉特征。

**只有文字、只有提示词、只有配色分析，都不算完成。**

## 核心原则

```text
Reference Image
→ Visual DNA
→ Bouquet Translation
→ Buildable Bouquet Spec
→ Bouquet Image
```

不是复制图片里的物体，而是保留它的视觉身份：

- `Color → 花材 / 包装 / 丝带`
- `Composition → 花束轮廓 / 高低 / 疏密 / 重心`
- `Texture → 材质与花材质感`
- `Symbol → 少量识别性点缀`
- `Mood → 饱和度 / 留白 / 克制程度`

生成的效果图必须与执行单是**同一束花**，并优先保证现实可制作性。

## 使用

安装本仓库中的 `SKILL.md` 后，直接把图片交给 Agent，例如：

> 把这张图做成一束花。输出花束效果图，并给我一份花艺师可以直接执行的制作方案。

Skill 会先理解参考图，再生成最终花束，而不是让用户先填写复杂参数。
