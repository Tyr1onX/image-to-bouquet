# Image to Bouquet

> 给一张图片，得到一束真实能做出来的花。

`image-to-bouquet` 会读取参考图里的 **色彩、构图、质感和氛围**，再把这些视觉关系转译成一束现实可制作、成本可控的花束。

它不追求把图片里的具体人物、建筑、Logo、文字、线稿或物体原样搬进花束，而是保留这张图最重要的视觉感觉。

```text
参考图片
  ↓
色彩 / 构图 / 质感 / 氛围
  ↓
真实可制作的花束
  ↓
花束成品图 + 花艺师执行单
```

## 怎么用

安装 Skill 后，直接给 Codex 一张图片，例如：

> 用 image-to-bouquet 把这张图转成一束花。

不需要提前指定花材。它会根据图片决定花材、包装、结构和整体配色。

参考图可以是风景、人物、随手拍、建筑、插画、海报、专辑封面，或者任何你觉得适合转成花束的图片。

## 你会得到什么

### 1. 花束成品图

一张独立、清晰的花束图片，只展示最终花束和简单背景。

花束会尽量满足：

- 看起来真实，而不是概念艺术；
- 花材、结构和包装能够被花艺师实际复现；
- 保留参考图最重要的颜色层级、冷暖关系和空间分区；
- 不把参考图中的具体物体或图形元素生硬地塞进花束；
- 主要可见元素都来自真实花材、配叶、包装和常规花艺材料；
- 颜色主要来自花材与包装本身，而不是靠红蓝灯光、霓虹灯或后期光效“染”出来。

### 2. 花艺师执行单

**花束图片生成完成并不代表任务结束。** Skill 还必须继续给出一份与最终成品完全对应的花艺师执行单。

执行单包括：

- 花束尺寸与结构；
- 花材和配叶；
- 每种材料的大致数量；
- 包装纸、内衬、丝带等外部材料；
- 简短制作顺序；
- 可替代材料；
- 成本等级；
- 最需要保留的视觉特征。

图片和执行单描述的是 **同一束花**，方便直接拿给花艺师参考。只返回图片、漏掉执行单，都属于不完整结果。

## 设计原则

### 视觉转译，而不是复制原图

```text
色彩 → 花材 / 包装 / 丝带
构图 → 花束轮廓 / 高低 / 重心 / 留白
质感 → 花材表面 / 配叶 / 包装材质
氛围 → 饱和度 / 密度 / 克制程度
```

对于专辑封面、海报、插画等包含文字、线稿、几何图形或界面元素的图片，这些内容只会影响 **色彩分区、方向、节奏、重心和留白**，不会被直接变成花束里的黑线、支架、金属框、亚克力片、灯管或其他抽象装置。

人物、人脸、五官、文字、Logo、原图碎片、专辑封面图案、可识别物体和场景也不会被印到包装纸、丝带、吊牌或任何花束部件上。

### 色彩不只是“取几个颜色”

Skill 会优先保留：

1. 大色块的位置关系，例如左冷右暖、上暗下亮；
2. 主色 / 次色 / 点缀色的大致比例；
3. 冷暖、明暗、饱和度之间的对比；
4. 必要的过渡色，避免最后变成颜色平均混在一起的普通花束。

如果某种颜色很难由鲜花自然实现，会优先通过包装、丝带、真实染色 / 永生花材或最接近的现实花色解决，而不是创造不存在的花、加灯或引入抽象装饰。

### 灯光不能替花材作弊

最终图片应当接近真实花店的产品摄影：

- 灯光位于画面外，不作为花束可见元素；
- 不出现 LED 灯条、霓虹管、灯棒、灯泡等主动光源；
- 不用强烈红蓝紫灯把原本不同颜色的花“染”成参考图配色；
- 不用发光、投影、光晕或 CGI 效果承担主要颜色；
- 即使放到普通自然光下，花束本身也应该保留主要配色关系。

### 真实可做是硬约束

默认花束中的主要可见元素只使用：

- 鲜花；
- 配叶和真实植物枝材；
- 干花、永生花或明确说明的染色花材；
- 必要时使用并明确说明的仿真花材；
- 普通花艺包装纸、内衬、丝带等常规花艺材料。

花艺铁丝、胶带等结构材料可以正常用于制作，但默认应隐藏，不能把它们当作视觉装饰。

默认不生成：

- 黑色线性装置、外露铁丝、几何支架；
- 金属杆、亚克力片、塑料图形、镜面或水晶装饰；
- LED 灯条、霓虹管、灯棒、灯泡等可见光源；
- Logo、文字卡片、原图碎片或象征性道具；
- 吊牌、标签、祝福卡、纸条、票据或其他无必要纸质插物；
- 漂浮物、模型、发光结构、CGI 效果；
- 无法明确说清材质和采购方式的抽象插物；
- 不存在的花朵或无法在现实中实现的花色与结构。

包装纸也必须像真实花店会使用的包装：以纯色、普通纹理、薄膜或纸张层叠为主，不应像海报、专辑封面、硬质面板或打印画布。

一个简单原则是：**如果花束里出现了某个醒目的东西，花艺师应该能够在执行单里明确知道它是什么、买什么、买多少、放在哪里；如果它只是为了“更酷”而存在，就不应该出现。**

### 默认控制成本

除非特别说明，默认以中小尺寸花束为主：

- 花材种类不过多；
- 主花数量适中；
- 优先使用常见、容易采购的材料；
- 能通过包装、丝带和配叶完成的颜色关系，不靠额外堆花解决。

目标不是做出最复杂、最昂贵的一束花，而是用尽可能简单、真实的方式，把参考图的感觉留下来。
