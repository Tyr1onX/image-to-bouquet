# Image to Bouquet

> 给一张图片，得到一束真正有设计感、而且现实中能做出来的花。

`image-to-bouquet` 会读取参考图里的 **配色、重心、节奏和气质**，再重新设计成花材与包装。

它不是把原图“拼成花”，而是把最重要的视觉感觉转成一束成立的花。

```text
参考图片
  ↓
色彩 / 重心 / 节奏 / 气质
  ↓
选择花材与包装
  ↓
重新做花艺设计
  ↓
成品图 + 花艺师执行单
```

## 怎么用

安装 Skill 后，直接给一张图片：

> 用 image-to-bouquet 把这张图转成一束花。

默认会自动选择材料，也可以指定：

- **Fresh**：鲜花
- **Preserved**：永生花优先，适合专辑封面和强配色参考图
- **Hybrid**：鲜花 + 永生花 / 干花 / 染色花材
- **Art**：设计与颜色优先，可加入高质量仿真植物

也可以补充：

> 颜色尽量贴近原图，永生花版本；有必要时局部做渐变，但不要为了渐变而渐变，包装也参与配色。

## 你会得到

- 一张独立的花束成品图；
- 一份对应的花艺师执行单，包含材料、数量、包装、替代方案与关键设计关系。

目标是：**颜色贴近、色彩关系合理、花型好看、包装有设计、整体有焦点与层次，同时花艺师真的能复现。**
